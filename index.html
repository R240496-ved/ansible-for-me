1. Update and install Ansible. sudo apt update sudo apt install ansible -y ansible --version 2. Create the practical folder. mkdir -p ~/ansible_pract cd ~/ansible_pract 3. Create the inventory file. nano inventory Write: [local] localhost ansible_connection=local Save: Ctrl + O → Enter → Ctrl + X 4. Create the playbook. nano tree.yml Write: --- - hosts: local become: yes tasks: - apt: name: tree state: present - file: path: /tmp/demo state: directory Save: Ctrl + O → Enter → Ctrl + X 5. Run the playbook. sudo ansible-playbook -i inventory tree.yml 6. Verify the results. ls -ld /tmp/demo tree --version tree /tmp/demo
